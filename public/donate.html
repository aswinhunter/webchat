About Me

Hi! I'm Aswin, a 20-year-old college student studying in Chennai. I'm passionate about building applications and learning new technologies.

I created this Chat Application purely for fun and learning. It features real-time group chats, one-to-one conversations, and video calling. The goal was to combine my interests in web development, real-time communication, and creating intuitive user experiences.

Working with Socket.io, Firebase, MongoDB, Node.js and other technologies has been an incredible learning journey. Your support means the world to me!
